## 1. 如何运行测试

服务端（Python venv）：

```bash
cd server
./.venv/Scripts/python.exe -m unittest discover -s tests -p "test_*.py"
```

Android 单元测试（JVM）：

```bash
./gradlew testDebugUnitTest
```

Android 仪器测试（需设备/模拟器）：

```bash
./gradlew connectedDebugAndroidTest
```

模拟上游自检（覆盖 E1 五种故障场景）：

```bash
python server/mock_upstream.py --selftest   # 期望 5/5 通过
```
