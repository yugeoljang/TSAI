## 0. 演示什么

在 App 里**选择 API 分组**发消息，请求走聚合网关（`POST /v1/chat/completions`，
`model` = 分组 routeKey）。网关按组成员优先级依次尝试上游；第一个上游故障时
**自动切换**到第二个，并在 App 的路由结果卡片上展示：

- 最终命中的上游（X-Upstream）
- 是否发生了故障切换（读 `/api/admin/requests/{id}/attempts`，attemptCount > 1）
- 请求 ID（点击复制，用于在 `/api/admin/requests` 追踪全程）

演示拓扑：

```
App ── POST /v1/chat/completions (model=demo) ──> 网关
                                                   ├─ 1st mock-fail (127.0.0.1:8100, scenario=500) ✗
                                                   └─ 2nd mock-ok   (127.0.0.1:8101, normal)      ✓ 返回
```

## 1. 准备：三个进程

```bash
# 终端 A：聚合服务（server/ 下）
# .env 先配固定主密钥，否则上游 Key 重启后解不开：
#   GATEWAY_MASTER_KEY=<64位hex>
python -m uvicorn app.main:app --reload --port 8000

# 终端 B：故障实例 8100
python mock_upstream.py

# 终端 C：正常实例 8101
MOCK_PORT=8101 python mock_upstream.py
```

## 2. 一键搭建分组

```bash
python setup_demo_group.py
```

脚本（幂等，可重跑）通过管理 API 创建：
`mock` 供应商 → `mock-fail`(8100) + `mock-ok`(8101) 两个上游 →
`demo` 分组（routeKey=`demo`）→ 成员顺序 fail(1) / ok(2)。
脚本还会尝试把 8100 切到 `scenario=500`、8101 保持 `normal`。

> 需要换顺序 / 重搭：先 `DELETE /api/admin/groups/{id}` 再重跑。

## 3. 命令行验证切换成立

```bash
# 发一次请求，走网关
curl -s -i http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"demo","messages":[{"role":"user","content":"你好"}]}'
```

期望：
- HTTP 200，`X-Request-Id` 头有值
- `X-Upstream` = `mock-ok`（第二个上游兜底成功，证明已切换）
- 取 `X-Request-Id` 查切换证据：

```bash
curl -s http://127.0.0.1:8000/api/admin/requests/<requestId>/attempts
```

期望两条记录：`mock-fail`(resultCategory=server_error, 500) →
`mock-ok`(resultCategory=success, 200)。

## 4. 在 App 里演示

1. `gradlew assembleDebug` 安装到模拟器（`AGGREGATOR_BASE_URL` 指向
   `http://10.0.2.2:8000/`，`usesCleartextTraffic=true` 已配）。
2. 打开「助手」页 →「路由方式」切到**分组路由** → 下拉选 `demo`。
3. 发任意消息：
   - 正常路径：回复来自 `mock-ok`，路由卡片显示「已切换」、尝试次数 2、
     最终上游 mock-ok、请求 ID 可复制。
   - 恢复直连：切回「直连」即走原有单供应商聊天，不受影响。
4. 验证失败信息不外泄：把 8101 也切到 500（`PUT 8101/_mock/scenario 500`）
   再发一次 → App 显示友好错误（网关 ErrorEnvelope 的 message），
   不展示上游内部 `sanitized_error` 明细。

## 5. 故障注入（可选）
